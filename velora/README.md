# VELORA 映堂

把一部短剧，当成一门课来看完。正片、分镜、表演与摄影精讲。

**页面地址：** https://dannyling111.github.io/velora/

仓库：https://github.com/dannyling111/velora

## 可以做什么

- 浏览 16 部短剧、8 个题材与 4 位创作者
- 搜索、筛选、试看第一集
- 加入购物车 / 心愿单（演示结算无需付款）
- 报名后在播放器里学习，进度与笔记保存在本机

## 本地预览

```bash
python3 -m http.server 8080
```
