# BFX Design · 量化排版引擎

A129 独立仓库网页：麦肯锡 / 投行 / 企业架构 / 行业研究 / 教学课件的专业幻灯片系统。内置模板数据库、十维量化调度与咨询级图表原语。

## 线上地址

- 首页：https://dannyling111.github.io/a129-bfx-design/
- 仓库：https://github.com/dannyling111/a129-bfx-design

纯静态站点，打开即可用。材料存在本机浏览器里。

## 怎么用

1. 打开工作室，点样例材料翻页
2. 模板库按品类看骨架
3. 量化引擎贴一段命题，看十维向量与调度
4. 「从简报装配」生成本地幻灯片，可导出 PPTX
5. 演示模式用左右方向键翻页

静态站点没有服务端模型润色，装配走本地量化引擎。

## 本地

打开 `index.html`，或：

```sh
python3 -m http.server 8080
```

随后访问 `/#/`。
